# HoaHong

Kho lưu các ứng dụng; mỗi ứng dụng nằm trong thư mục riêng.

- [InBaoCao](InBaoCao/README.md): bản Python, trộn Excel vào mẫu Word bằng keyword và in hàng loạt. Chạy `CaiDat.cmd`, sau đó `CHAY_PHAN_MEM.bat`; đóng gói bằng `DONG_GOI_EXE.bat`.

- [KySoPython](Kyso/README.md): bản Python hỗ trợ ký hồ sơ trên admin.csdlksk.vn bằng Chrome và USB Token. Có bộ cài dependency, giao diện chọn hồ sơ và cấu hình đóng gói EXE Windows; cần kiểm chứng ký thật trên Windows.

Tải riêng mã nguồn InBaoCao: [InBaoCao-Source.zip](InBaoCao-Source.zip). Giải nén vào thư mục mới; không chép đè lên bản Electron cũ.

Tải mã nguồn ký số: [Kyso-Source.zip](Kyso-Source.zip). Giải nén, mở thư mục `Kyso`, chạy `CaiDat.cmd` rồi `CHAY_PHAN_MEM.bat`.
