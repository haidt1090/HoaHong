# InBaoCao Windows — Python 2.0

InBaoCao sử dụng Python và Tkinter. Xem [hướng dẫn mới](../HUONG_DAN.txt).

Chạy `CaiDat.cmd` một lần, sau đó `CHAY_PHAN_MEM.bat`. Build bằng `DONG_GOI_EXE.bat`; kết quả `dist/InBaoCao.exe`. Không dùng npm hoặc bộ cài NSIS nữa. In trực tiếp cần Microsoft Word desktop đã cài trên Windows.
