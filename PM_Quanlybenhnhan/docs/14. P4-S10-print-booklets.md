# Phase 4 — Sprint 10: Print Booklets

- **Phase:** 4 — Reports & Printing
- **Sprint:** 10
- **Priority:** 🟡 High
- **Django App(s):** `reports` (print templates), frontend print component
- **Depends on:** Sprint 9 (report infra), Phase 2 (examinations + department results)

---

## Goal

Produce printable examination booklets for the four checkup types. The booklet layout now renders departments dynamically from `DepartmentResult` rows (one block per department) instead of 5 hard-coded sections.

---

## Tasks

- [ ] Print template for 4 booklet types:
  1. **Khám sức khỏe định kỳ** (Periodic Health Check)
  2. **Khám sức khỏe nghề nghiệp** (Occupational Health)
  3. **Khám bố trí nghề nghiệp** (Job Placement)
  4. **Khám lao động trên/dưới 18 tuổi** (Labor Under/Over 18)
- [ ] Layout: each department rendered as a **table block** with department name as heading
  - Columns from `template_snapshot`: field label, value, unit, normal range indicator
  - Abnormal values highlighted (outside normal_range)
- [ ] Cover page: clinic logo, patient info, QR code, barcode, list of departments examined
- [ ] Frontend print component:
  - Fetches `GET /api/examinations/{id}/` with nested department_results
  - Renders all department tables + cover page
  - `window.print()` with `@media print { @page { size: A4; } }`
- [ ] Batch print: select multiple patients → combined document
- [ ] `GET /api/print/{exam_id}/preview/` (returns print-ready HTML)
