- **Phase:** 2 — Examination Core
- **Sprint:** 4
- **Priority:** 🔴 Critical
- **Django App(s):** `examinations`
- **Depends on:** Phase 1 (auth, patients, companies)

## Goal

Replace the old fixed-section ExamTemplate with a fully dynamic **department-driven** template system. Any medical department (Lâm sàng, Xét nghiệm máu, Xét nghiệm nước tiểu, X-Quang, Siêu âm, Da liễu, Mắt, TMH, ...) can be created and each has its own column definitions via `DepartmentTemplate`. Departments are grouped into `ExamPackage` for company registration.

## Data Model

```python
class Department(BaseModel):
    name = models.CharField(max_length=255)
    code = models.CharField(max_length=50, unique=True)
    category = models.CharField(max_length=20, choices=[('clinical', 'Lâm sàng'), ('para_clinical', 'Cận lâm sàng')], default='clinical')
    description = models.TextField(blank=True)
    is_active = models.BooleanField(default=True)

class DepartmentTemplate(BaseModel):
    department = models.ForeignKey(Department, on_delete=models.CASCADE, related_name='templates')
    name = models.CharField(max_length=255)
    version = models.IntegerField(default=1)
    is_active = models.BooleanField(default=True)
    created_by = models.ForeignKey(User, on_delete=models.SET_NULL, null=True)  # auto-set, read-only in admin

    @property
    def fields_config(self) -> list[dict]:
        """Serialize related DepartmentField rows into the legacy JSON array shape.

        Used by the render API and by DepartmentResult.template_snapshot so that
        downstream sprints (5, 9, 10, 10a, diagnosis) keep the same data format.
        """
        return [f.as_config() for f in self.fields.all().order_by('order')]

class DepartmentField(BaseModel):
    FIELD_TYPES = [
        ('text', 'Text'), ('number', 'Number'), ('select', 'Select'),
        ('multi_select', 'Multi-select'), ('boolean', 'Boolean'),
        ('date', 'Date'), ('textarea', 'Textarea'),
    ]
    template = models.ForeignKey(DepartmentTemplate, on_delete=models.CASCADE, related_name='fields')
    key = models.CharField(max_length=100)              # auto-slugified from label
    label = models.CharField(max_length=255)
    field_type = models.CharField(max_length=20, choices=FIELD_TYPES, default='text')
    unit = models.CharField(max_length=50, blank=True)
    required = models.BooleanField(default=False)
    order = models.IntegerField(default=0)
    normal_range = models.JSONField(null=True, blank=True)   # {"min": .., "max": ..}
    default_value = models.JSONField(null=True, blank=True)  # NEW: pre-fills DepartmentResult.data[key]
    default_price = models.DecimalField(max_digits=12, decimal_places=0, default=0)
    test_category = models.CharField(max_length=50, blank=True)
    options = models.JSONField(default=list, blank=True)     # for select / multi_select

    class Meta:
        ordering = ['order']
        constraints = [
            models.UniqueConstraint(fields=['template', 'key'], name='unique_field_key_per_template'),
        ]
        indexes = [
            models.Index(fields=['key']),
            models.Index(fields=['template', 'order']),
        ]

    def as_config(self) -> dict:
        """Return this field as a fields_config dict entry (legacy shape)."""
        cfg = {
            'key': self.key, 'label': self.label, 'type': self.field_type,
            'order': self.order, 'required': self.required,
        }
        if self.unit:
            cfg['unit'] = self.unit
        if self.normal_range:
            cfg['normal_range'] = self.normal_range
        if self.default_value is not None:
            cfg['default_value'] = self.default_value
        if self.default_price:
            cfg['default_price'] = int(self.default_price)
        if self.test_category:
            cfg['test_category'] = self.test_category
        if self.options:
            cfg['options'] = self.options
        return cfg

class ExamPackage(BaseModel):
    EXAM_TYPES = [
        ('periodic', 'Khám định kỳ'),
        ('occupational', 'Khám nghề nghiệp'),
        ('job_placement', 'Khám bố trí nghề nghiệp'),
        ('labor_under18', 'Khám lao động dưới 18'),
        ('labor_over18', 'Khám lao động trên 18'),
    ]
    name = models.CharField(max_length=255)
    description = models.TextField(blank=True)
    exam_type = models.CharField(max_length=50, choices=EXAM_TYPES)
    departments = models.ManyToManyField(Department, through='ExamPackageDepartment')
    default_package_price = models.DecimalField(max_digits=12, decimal_places=0, null=True, blank=True)
    is_active = models.BooleanField(default=True)

class ExamPackageDepartment(BaseModel):
    exam_package = models.ForeignKey(ExamPackage, on_delete=models.CASCADE)
    department = models.ForeignKey(Department, on_delete=models.CASCADE)
    template = models.ForeignKey(DepartmentTemplate, on_delete=models.PROTECT)
    order = models.IntegerField(default=0)
    class Meta:
        ordering = ['order']
```

## Field Definitions (`DepartmentField` rows)

Each `DepartmentField` row is one column of a department's tabular form. The
`DepartmentTemplate.fields_config` **property** serializes these rows into the
JSON array below — the exact shape consumed by the render API, the frontend
`FieldDefinition` type, and `DepartmentResult.template_snapshot`. The storage
changed (JSON → table) but **the serialized shape did not**.

```json
[
  {
    "key": "hemoglobin",
    "label": "Huyết sắc tố",
    "type": "number",
    "unit": "g/dL",
    "required": true,
    "order": 1,
    "normal_range": { "min": 12, "max": 16 },
    "default_value": null,
    "default_price": 50000,
    "test_category": "blood"
  },
  {
    "key": "blood_pressure_systolic",
    "label": "Huyết áp tâm thu",
    "type": "number",
    "unit": "mmHg",
    "required": true,
    "order": 1,
    "default_value": 120,
    "default_price": 15000,
    "test_category": "clinical"
  }
]
```

Key differences from old design:
- **Stored as `DepartmentField` rows** (not a JSON array) — enables indexing,
  per-field queries, and search (e.g. "all templates with a hemoglobin field",
  "fields with `test_category='blood'`").
- **No more `sections`** — each DepartmentTemplate IS a section. The ExamPackage groups them.
- **`default_value`** — pre-fills `DepartmentResult.data[key]` when the exam spawns results (Sprint 5).
- **`default_price` per field** — used for per-field pricing mode.
- **`test_category`** — used by the test screening report (Sprint 10a).
- **`gender_overrides`** — optional per-gender normal range + random step:

```json
"gender_overrides": {
  "M": { "min": 3.5, "max": 7.5, "step": 0.2 },
  "F": { "min": 3.0, "max": 7.0, "step": 0.2 }
}
```

  When seeding an empty numeric field (no field-level `default_value`), the
  system picks a random value in `[min, max]`. The pick is discrete:
  `min`, `min+step`, … up to `max` (e.g. `3.5, 3.7, …, 7.5` with `step: 0.2`).
  If `step` is omitted, it defaults to **0.1**. Base normal range (no gender
  override) still uses continuous uniform random. Legacy override key
  `default` is ignored — use field `default_value` for a fixed seed.

## Technical Notes

- `ExamPackageDepartment.template` freezes which template version is active for that package. If the template is updated (new version), existing packages keep the old version.
- Department CRUD is Admin-only (per CMS role in Sprint 2a).
- ExamPackage and Template CRUD are also Admin/Doctor (create) per matrix.
- Seed departments on first migration: "Khám lâm sàng", "Xét nghiệm", "X-Quang", "Siêu âm".
- **DepartmentField vs template_snapshot**: `DepartmentField` rows are the *editable source of truth*. `DepartmentResult.template_snapshot` is a *frozen JSON copy* taken at examination-creation time (Sprint 5). Editing a `DepartmentField` later does NOT change existing snapshots — versioning + snapshotting preserve historical data.
- **`fields_config` property**: `DepartmentTemplate.fields_config` is now a computed property (`[f.as_config() for f in fields.order_by('order')]`), not a stored column. Existing code that reads `template.fields_config` keeps working. Any code that *wrote* to it must instead create/update `DepartmentField` rows.
- **`default_value`**: type follows `field_type` (number → int/float, boolean → bool, select → one of `options`, etc.). Stored as JSON to stay type-flexible. Null means "no default".
- **Auto-key**: `key` is derived from `label` using Unicode NFD normalization + `đ`/`Đ` → `d`/`D` mapping + non-alphanumeric → `_` fallback. Editing an existing field preserves the original key. Collisions resolve via numeric suffix. Uniqueness enforced at DB level by `UniqueConstraint(template, key)`.
- **`created_by`**: read-only in Django Admin; set to `request.user` on first save via `save_model()`. Not overwritten on subsequent edits. API serializer also auto-sets it from the request user.
- **Search benefit**: `DepartmentField.objects.filter(key=..., test_category=..., normal_range__max__gt=...)` becomes possible with indexes, which the old JSON array could not do efficiently.
