# Phase 2 — Sprint 4b: Department Hierarchy (Parent-Child)

- **Phase:** 2 — Examination Core
- **Sprint:** 4b (patch to S4)
- **Priority:** 🟡 Medium
- **Django App(s):** `examinations`
- **Depends on:** Sprint 4 (dynamic form engine)

---

## Goal

Add hierarchical structure to Departments: parent-child relationship, tree API endpoint, and admin support. Templates, exam packages, results, and RBAC remain bound to leaf departments — no business logic changes.

---

## Design Rules

| Rule | Detail |
|---|---|
| Template attached at | **Leaf only** (child departments) |
| Package bindings point to | **Individual child departments** |
| Category inheritance | **None** — each department has its own category |
| Permissions | **Unchanged** — `can_edit_department` checks the specific leaf |

## API Contract

### `GET /api/departments/tree/`

Response:
```json
[
  {
    "id": "uuid-1",
    "name": "Khám lâm sàng",
    "code": "kham_lam_sang",
    "category": "clinical",
    "children": [
      {
        "id": "uuid-2",
        "name": "Khám mắt",
        "code": "kham_mat",
        "category": "clinical",
        "children": []
      }
    ]
  }
]
```

### `GET /api/departments/?parent=<id>`

List children of a specific department. `?parent=null` or omit `parent` for all.
