# Phase 6 — Sprint 14: Online Result Portal

- **Phase:** 6 — QR Code & Online Results
- **Sprint:** 14
- **Priority:** 🟢 Medium
- **Django App(s):** `results` (public views), frontend portal
- **Depends on:** Sprint 13 (QR), Phase 2 (examinations), Phase 4 (PDF)

---

## Goal

Provide a public, mobile-friendly result portal where patients look up their own examination results (via QR or company_code + employee_code + DOB) and download a PDF. Company admins can view all their employees' results.

---

## Tasks

- [ ] Public result lookup (no auth; secured by QR + password):
  ```
  GET /khamsk/result/?code=<encrypted_qr_code>
  ```
- [ ] Alternative login:
  ```
  POST /api/results/login/
  Input:
    - Có công ty: { company_code, employee_code, password: dob (YYYY-MM-DD) }
    - Cá nhân:    { cccd, password: dob (YYYY-MM-DD) }
  Output: { token, patient_info }
  ```
- [ ] Result display page:
  - Patient info (name, dob, gender, company)
  - Examination date, type
  - Department results: one block per department (Lâm sàng, Xét nghiệm, X-Quang, Siêu âm, ...)
  - Each department block shows a table: field label, value, unit, normal range indicator (green/red)
  - Doctor's conclusion and diagnosis
  - PDF download button
- [ ] Security:
  - Rate limiting (5 attempts / IP / minute)
  - Token expiry (30 min)
  - Encrypted QR codes (cannot guess other patient's URL)
  - No PII in the QR code itself
- [ ] Company admin view:
  - `GET /api/results/company/` (list all employees with results)
  - Filter by date range, department, status
  - Download batch results as ZIP
- [ ] Frontend: mobile-responsive for patient access on phones

---

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/results/login/` | Login: company_code + employee_code + DOB |
| GET | `/api/results/{token}/` | View result data |
| GET | `/api/results/{token}/pdf/` | Download result PDF |
| GET | `/api/results/company/` | Company admin: all employees' results |

---

## Acceptance Criteria

- Patient can log in via company_code+employee_code+DOB OR cccd+DOB (cá nhân) and see only their own result
- Only `confirmed` examinations are visible in the portal
- Lab results show normal/abnormal indicators against reference ranges
- PDF download matches the on-screen result
- Brute-force attempts are rate-limited; tokens expire after 30 min
- CompanyAdmin sees only their own company's employees
- Portal is usable on mobile screens

---

## Security Notes

- Treat the portal as an untrusted public surface: strict input validation, no PII leakage in URLs/QR.
- Scope every query to the authenticated patient/company — never trust client-supplied ids.
- Log access attempts for audit.
