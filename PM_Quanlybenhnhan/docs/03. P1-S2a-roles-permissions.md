## Goal

Define and enforce the role-based access control (RBAC) that governs the entire system. Permission control now operates at the **department level**: a Nurse can edit clinical departments, a LabTech can edit lab/imaging departments, a Doctor can edit all and write the conclusion.

---

## Roles

| Role | Who | Key Responsibilities |
|------|-----|---------------------|
| **Admin** (Quản trị viên) | System administrator | Full access: users, companies, departments, templates, packages, pricing, reports, settings |
| **Doctor** (Bác sĩ) | Clinic doctor | All departments; conclusion; confirm exams; view all reports |
| **Nurse** (Điều dưỡng) | Nursing staff | Edit **clinical departments** (Lâm sàng, Mắt, Da liễu, TMH, ...); create draft exams; print booklets; scan QR |
| **LabTech** (Kỹ thuật viên) | Lab technician | Edit **para-clinical departments** (Xét nghiệm, X-Quang, Siêu âm, ...); generate QR; cannot edit clinical |
| **CompanyAdmin** (Công ty) | Company HR | View own company's employee results; generate/download reports; no medical data editing |
| **Patient** (Bệnh nhân) | Public | View own result only via public portal |

## Department-Level Permission Implementation

Instead of field-level locking on JSONFields, permissions are enforced by **department category** (`Department.category`):

```python
# Role → department category access mapping (runtime lookup)
ROLE_DEPT_CATEGORY = {
    'nurse': 'clinical',
    'labtech': 'para_clinical',
}

class DepartmentResultPermission(BasePermission):
    def has_permission(self, request, view):
        role = request.user.role
        if role in ('admin', 'doctor'):
            return True
        # Runtime lookup: view resolves department object → checks category
        department = getattr(view, 'get_department', lambda: None)()
        if department is None:
            return True  # defer to object-level check
        return can_edit_department(role, department)
```

`DepartmentResult` records which department it belongs to (via FK) — permission is resolved at **runtime** by `Department.category`.

## UI Enforcement Rules

- **Department-level locking**: Tabs for departments the user cannot edit are shown with a lock icon and disabled inputs
- **Status workflow**: `draft` → `completed` → `confirmed`. Only `draft` exams can be deleted. `confirmed` exams are immutable except by Admin
- **Audit trail**: All edits logged via `django-simple-history`
- Each DepartmentResult records `completed_by` — tracks who filled which department

## Acceptance Criteria

- Nurse saves clinical department data (`category='clinical'`) → 200; saves para-clinical department → 403
- LabTech saves para-clinical department data (`category='para_clinical'`) → 200; saves clinical → 403
- Doctor saves any department + conclusion → 200
- The API returns which department codes are editable by the current user
- Non-assigned department tabs are visually locked in the UI
