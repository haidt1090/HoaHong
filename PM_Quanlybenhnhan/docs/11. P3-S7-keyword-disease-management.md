## Goal

Model the disease codes and diagnosis keywords from `Benh-TuVan 001.xlsx`, import them into the database, and expose CRUD + search APIs. The diagnosis engine works across all department results — keywords match against findings text aggregated from all `DepartmentResult.data` values.

Additionally:

- Define **abnormal thresholds per field** so that numeric values outside the normal range are automatically translated into human-readable labels (e.g., HR=52 → "Nhịp tim chậm") before being fed to the diagnosis engine.
- Track **phân loại bệnh mắc** (disease classification) on each keyword so the doctor gets a work-fitness conclusion (đủ / không đủ điều kiện lao động).

## Data Model

### DiseaseCode

- `code`: CharField (unique, e.g. "NOI", "MAT", "XN")
- `disease_name`: TextField
- `icd_code`: CharField (max_length=10, blank=True)
- `description`: TextField (blank=True)
- `group`: CharField (`occupational` / `periodic` / `general`)
- `is_active`: BooleanField

### DiagnosisKeyword

- `keyword`: TextField (symptom/finding pattern)
- `disease`: FK → DiseaseCode
- `conclusion_template`: TextField (tư vấn — conclusion text to output)
- `exam_type`: CharField (which exam type this applies to)
- `classification`: PositiveSmallIntegerField (null=True, blank=True) — phân loại bệnh mắc
- `priority`: IntegerField (higher = matched first; currently all 0, kept for future)
- `is_active`: BooleanField
- `embedding`: JSONField (null=True) — populated in Sprint 8

**`classification` values** (mapped from Excel column F "Phân loại bệnh mắc"):

| Value | Constant | Meaning |
|-------|----------|---------|
| 0 | `CLASSIFICATION_NORMAL` | Bình thường |
| 1 | `CLASSIFICATION_UNFIT` | Không đủ điều kiện lao động |
| 2 | `CLASSIFICATION_DISEASE` | Bệnh mắc |
| 5 | `CLASSIFICATION_MILD` | Nhẹ |

### DepartmentFieldAbnormal

- `field`: FK → DepartmentField (`related_name='abnormal_definitions'`)
- `direction`: CharField (`low` = dưới ngưỡng / `high` = trên ngưỡng)
- `label`: CharField (human-readable label, e.g. "Nhịp tim chậm", "Tăng men gan")
- `keyword`: FK → DiagnosisKeyword (null=True, optional — links to the keyword that will be matched)
- `UniqueConstraint(field, direction)` — one definition per direction per field

### Examination (extended in this sprint)

- `disease`: **ManyToManyField** → DiseaseCode (was TextField; now supports multiple diseases per exam)
- `consultation`: TextField (tư vấn từ kết quả chẩn đoán)
- `conclusion`: TextField (ghi chú kết luận tự do của bác sĩ)
- `work_fitness`: CharField — kết luận đáp ứng điều kiện lao động

**`work_fitness` values**:

| Value | Display |
|-------|---------|
| `pending` | Chưa kết luận (default) |
| `fit` | Đủ điều kiện lao động |
| `unfit` | Không đủ điều kiện lao động |

## Diagnosis Flow

```
DepartmentResult (all departments)
    → aggregate_findings(examination)
        · number out-of-range + abnormal_def → "Nhịp tim chậm"
        · number within normal range → SKIPPED
        · text "bình thường"/"-"/"normal" → SKIPPED
        · text matching known keyword → SKIPPED
        · otherwise → "label: value"
    → findings text
    → match_diagnosis(findings_text, exam_type)
        · iterate active keywords ordered by -priority
        · substring match (keyword in part OR part in keyword)
        · dedupe by disease code
        · return [{keyword, disease_code, disease_name,
                   conclusion_template, classification, priority}]
    → frontend ConclusionSection
        · shows matches + classification tags
        · auto-default work_fitness = 'unfit' if any match classification=1
        · auto-fill consultation from conclusion_template
```

`DiseaseCode` is only a classification group; the actual symptom→disease mapping lives in `DiagnosisKeyword.keyword`, and tư vấn text lives in `DiagnosisKeyword.conclusion_template`.

## DepartmentFieldAbnormal Design

```
DepartmentField                    DepartmentFieldAbnormal
┌──────────────────────┐          ┌─────────────────────────────┐
│ key: "hr"            │──1:N──▶  │ direction: "low"            │
│ label: "Nhịp tim"    │          │ label: "Nhịp tim chậm"      │
│ normal_range_min: 60 │          │ keyword ──▶ DiagnosisKeyword │
│ normal_range_max:135 │          ├─────────────────────────────┤
│ field_type: "number" │          │ direction: "high"           │
└──────────────────────┘          │ label: "Nhịp tim nhanh"     │
                                  │ keyword ──▶ DiagnosisKeyword │
                                  └─────────────────────────────┘
```

```python
class DepartmentFieldAbnormal(BaseModel):
    DIRECTION_CHOICES = [('low', 'Dưới ngưỡng'), ('high', 'Trên ngưỡng')]
    field = ForeignKey(DepartmentField, related_name='abnormal_definitions', on_delete=CASCADE)
    direction = CharField(max_length=5, choices=DIRECTION_CHOICES)
    label = CharField(max_length=255)  # "Nhịp tim chậm"
    keyword = ForeignKey(DiagnosisKeyword, null=True, blank=True, on_delete=SET_NULL)
    class Meta:
        constraints = [UniqueConstraint(fields=['field','direction'], name='unique_abnormal_per_field')]
```

## Findings Aggregation

```python
# diagnosis/services.py
def aggregate_findings(examination):
    parts = []
    known_keywords = list(DiagnosisKeyword.objects.filter(is_active=True).values_list("keyword", flat=True))
    for dept_result in examination.department_results.all():
        snapshot = dept_result.template_snapshot or []
        data = dept_result.data or {}
        for field in snapshot:
            key = field.get("key")
            value = data.get(key)
            if value is None or value == "":
                continue
            field_type = field.get("type", "text")
            label = field.get("label", key)

            if field_type == "number":
                nr = field.get("normal_range")
                if nr and (nr.get("min") is not None or nr.get("max") is not None):
                    abnormal_defs = {
                        ad["direction"]: ad["label"]
                        for ad in field.get("abnormal_definitions", [])
                    }
                    val = float(value)
                    lo, hi = nr.get("min"), nr.get("max")
                    if lo is not None and val < lo and "low" in abnormal_defs:
                        parts.append(abnormal_defs["low"]); continue
                    if hi is not None and val > hi and "high" in abnormal_defs:
                        parts.append(abnormal_defs["high"]); continue
                    if (lo is None or val >= lo) and (hi is None or val <= hi):
                        continue  # within normal range — skip
            # Skip normal-indicating text
            if str(value).strip().lower() in ("bình thường", "binh thuong", "normal", "-"):
                continue
            # Skip values that already match a known keyword
            if any(kw.lower() in str(value).lower() for kw in known_keywords):
                continue
            parts.append(f"{label}: {value}")
    return ", ".join(parts)
```

Example output:
```
"Nhịp tim chậm, Á sừng da đầu, Tăng men gan"
```
