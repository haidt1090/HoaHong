# Phase 1 — Frontend Sprint: App Shell, Auth, Patients & Companies

- **Phase:** 1 — Foundation
- **Sprint:** F1 (companion to Phase 1 backend sprints)
- **Priority:** 🔴 Critical
- **Depends on:** Sprint 1-3 backend APIs (auth, patients, companies)
- **Runs in parallel with:** Sprint 3
- **Status:** Done

---

## Goal

Set up the SPA project, app shell (layout, routing, auth guard), login/page, patient/company CRUD pages, and the **Company Package assignment page** (wiring up Sprint 6a backend when ready).

- [x] Axios wrapper: base URL, JWT interceptor, auto-refresh, offline detection stub
- [x] ESLint + Prettier + vue-tsc type-check

### Auth Pages
- [x] Login page (email + password)

### Patient Management Pages
- [x] Patient list (table: employee_code, full_name, dob, gender, company, department, status)
  - Search bar, filters (company dropdown), pagination
- [x] Patient create/edit form (shared `PatientForm` component)
  - Company selector dropdown (optional — "Không thuộc công ty / Cá nhân" option via ToggleSwitch)
  - If company selected: employee_code required + validated unique per company
  - If cá nhân (no company): employee_code hidden, định danh bằng cccd hoặc phone
  - CCCD format validation (9 or 12 digits)
  - Toggle: "Có công ty" / "Cá nhân" switches form mode
  - Removed: "Yếu tố độc hại" field (đã bỏ)
- [x] Patient detail page
  - Personal info + examination history timeline (`ExaminationTimeline`)
  - "Sửa" / "Xóa" buttons (role-gated)

### Company Management Pages
- [x] Company list (table: name, tax_code, contact, employee count)
  - Search bar, pagination
- [x] Company create/edit form (shared `CompanyForm` component)
- [x] Company detail page with tabs (Info + Employees via `EmployeeListTab`)

### Company Package Assignment Page
- [x] Route: `/companies/{id}/packages/`
- [x] List assigned packages as cards (`PackageCard` in `PackageList`: name, pricing mode, total cost)
- [x] "Gán gói khám" button → `PackageAssignmentModal`:
  - Select exam package from dropdown
  - Choose pricing mode via `PricingModeToggle`:
    - Per-field: `PricingFieldTable` of all department fields with editable price inputs (pre-filled with template's `default_price`)
    - Package total: single price input
  - Save
- [x] Edit/Deactivate buttons per assigned package
- [x] Note: backend endpoint `POST /api/companies/{id}/packages/` is ready from Sprint 3 (CompanyExamPackage); full per-field price persistence is in Sprint 6a

### State Management
- [x] Auth store (`stores/auth.ts`), patient store, company store, package store

### Common Components (UI Library)
- [x] DataTable (wraps PrimeVue DataTable), SearchBar (debounced), PageHeader (title + breadcrumb)
- [x] FormField (label + error + help-text), StatusBadge (tag with severity mapping), ActionMenu
- [x] EmptyState, LoadingSkeleton (table/card/form), SectionCard, InfoRow
- [x] ConfirmDialog (wraps PrimeVue useConfirm), Toast (wraps PrimeVue useToast)

### Backend Fixes (ad-hoc)

- [x] `api_exception_handler` — simplified from `{"error": {"code": "...", "detail": "...", "fields": {...}}}` to standard `{"detail": "...", "code": "..."}` format
- [x] `Patient.toxic_factors` — removed from model, serializer, migration `0003_remove_toxic_factors`
