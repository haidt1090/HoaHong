## Goal

When a company registers for employee examination, an admin assigns them an `ExamPackage` and configures pricing — either per-field (mỗi chỉ số có giá riêng) or flat package price (giá trọn gói). This creates a `CompanyExamPackage` record that drives cost reports and examination creation.

## Tasks

- [ ] `CompanyExamPackage` model:
  - `company`: FK → Company
  - `exam_package`: FK → ExamPackage (`PROTECT`, `related_name='company_packages'`)

- [ ] CompanyExamPackage CRUD endpoints:
  - `GET /api/companies/{id}/packages/` (list assigned packages for a company)
  - `POST /api/companies/{id}/packages/` (assign package with pricing)
  - `PUT /api/companies/{id}/packages/{pkg_id}/` (update pricing or deactivate)
- [ ] Pricing calculation endpoint:
  - `GET /api/companies/{id}/packages/{pkg_id}/price-preview/`
  - Returns computed total based on pricing_mode
- [ ] Flow:
  ```
  1. Admin selects company → existing ExamPackage
  2. Admin chooses pricing_mode:
     a. Per-field: computes total from all template default_prices × total_employees
     b. Package total: uses ExamPackage.default_package_price × total_employees
  3. Saved as CompanyExamPackage
  4. When examination is created for this company, CompanyExamPackage is referenced
  ```

## Data Model

```python
class CompanyExamPackage(BaseModel):
    PRICING_MODES = [
        ('per_field', 'Theo từng chỉ số'),
        ('package_total', 'Theo giá trọn gói'),
    ]
    company = models.ForeignKey(Company, on_delete=models.CASCADE, related_name='exam_packages')
    exam_package = models.ForeignKey('examinations.ExamPackage', on_delete=models.PROTECT, related_name='company_packages')
    pricing_mode = models.CharField(max_length=20, choices=PRICING_MODES)
    total_employees = models.PositiveIntegerField(default=0, help_text='Số lượng nhân viên được khám theo gói này')
    is_active = models.BooleanField(default=True)
    assigned_at = models.DateTimeField(auto_now_add=True)
    assigned_by = models.ForeignKey(User, on_delete=models.SET_NULL, null=True)

    class Meta:
        unique_together = ['company', 'exam_package']
        ordering = ['-assigned_at']
```

## Pricing Flow

### Per-Field Mode
```
DepartmentTemplate fields:
  hemoglobin: default_price = 50,000
  ALT:        default_price = 40,000
  cholesterol:default_price = 35,000
  ...

Cost per employee = sum of all template default_prices
Total cost = total_employees × cost_per_employee
```

### Package Total Mode
```
ExamPackage.default_package_price = 500,000
Total cost = total_employees × 500,000 (flat)
```

### Price Preview Endpoint
```
GET /api/companies/{id}/packages/{pkg_id}/price-preview/
Returns:
{
  "mode": "per_field",
  "total_employees": 50,
  "cost_per_employee": 285000,
  "grand_total": 14250000
}
```

## Technical Notes

- Per-field mode sums `default_price` from each field in all department templates of the package (no per-company price overrides).
- Package total mode uses `ExamPackage.default_package_price`.
- Integrates with cost report in Sprint 9: compute per-patient cost from pricing_mode + template defaults.
- `unique_together` ensures one active assignment per company-package pair.
