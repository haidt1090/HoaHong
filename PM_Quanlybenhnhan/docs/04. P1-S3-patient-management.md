## Data Model

```python
class Company(BaseModel):
    name = models.CharField(max_length=255)
    address = models.TextField(blank=True)
    tax_code = models.CharField(max_length=20, blank=True)
    contact_person = models.CharField(max_length=255, blank=True)
    contact_phone = models.CharField(max_length=20, blank=True)
    contact_email = models.EmailField(blank=True)
    is_active = models.BooleanField(default=True)

class Patient(BaseModel):
    company = models.ForeignKey(Company, on_delete=models.SET_NULL, null=True, blank=True, related_name='patients')
    employee_code = models.CharField(max_length=50, blank=True)
    full_name = models.CharField(max_length=255)
    dob = models.DateField()
    gender = models.CharField(max_length=1, choices=[('M', 'Nam'), ('F', 'Nữ')])
    cccd = models.CharField(max_length=20, blank=True)
    cccd_issued_date = models.DateField(null=True, blank=True)
    cccd_issued_place = models.CharField(max_length=255, blank=True)
    address = models.TextField(blank=True)
    phone = models.CharField(max_length=20, blank=True)
    email = models.EmailField(blank=True)
    department = models.CharField(max_length=255, blank=True)
    start_date = models.DateField(null=True, blank=True)
    toxic_factors = models.TextField(blank=True, help_text="Yếu tố độc hại")
    is_active = models.BooleanField(default=True)
    notes = models.TextField(blank=True)
    # embedding VectorField added Sprint 8

    class Meta:
        constraints = [
            models.UniqueConstraint(
                fields=['company', 'employee_code'],
                condition=models.Q(company__isnull=False),
                name='unique_employee_per_company'
            )
        ]

class CompanyExamPackage(BaseModel):
    PRICING_MODES = [
        ('per_field', 'Theo từng chỉ số'),
        ('package_total', 'Theo giá trọn gói'),
    ]
    company = models.ForeignKey(Company, on_delete=models.CASCADE, related_name='exam_packages')
    exam_package = models.ForeignKey('examinations.ExamPackage', on_delete=models.PROTECT, related_name='company_packages')
    pricing_mode = models.CharField(max_length=20, choices=PRICING_MODES)
    total_employees = models.PositiveIntegerField(default=0, help_text='Số lượng nhân viên được khám theo gói này')
    is_active = models.BooleanField(default=True)
    assigned_at = models.DateTimeField(auto_now_add=True)
    assigned_by = models.ForeignKey(User, on_delete=models.SET_NULL, null=True)

    class Meta:
        unique_together = ['company', 'exam_package']
        ordering = ['-assigned_at']
```

## Acceptance Criteria

- CRUD works for Patient and Company with role scoping enforced
- Search returns correct results for partial name / employee_code / cccd / phone
- `DELETE` performs soft delete (`is_active=False`)
- `unique_employee_per_company` constraint prevents duplicate employee_code within same company; NULL company (cá nhân) has no such constraint
- CompanyAdmin only sees patients from their own company; cá nhân patients visible to all staff
- Patient detail returns examination history timeline
- Creating patient without company (cá nhân) works — company field is optional
- CompanyExamPackage model exists and basic CRUD works
